# 电脑健康看板

把这台 Windows 电脑的处理器、内存、硬盘、网络状态做成一张看得懂的健康看板。

双击 `电脑健康看板.exe` 即可使用，不必安装 Python。程序会打开本地网页，并在右下角托盘常驻。

仓库地址：https://github.com/Suny0u17g/computer-health-board

## 它能告诉你什么

打开后先看最上面的结论，不用自己猜数字：

- **状态良好**：可以放心用
- **需要留意**：还能用，但有变慢苗头（橙色）
- **有问题**：可能卡顿或空间不够（红色）

每项都会用大白话说明：

- 处理器忙不忙
- 内存够不够
- 硬盘还剩多少（系统盘 / 资料盘）
- 网络有没有连上、是不是在大量传数据
- 谁最占内存（常见程序会翻译成中文）

数据只在本机流转，不会上传。

## 直接使用（推荐）

1. 下载本仓库里的 [`电脑健康看板.exe`](./电脑健康看板.exe)
2. 双击运行
3. 浏览器会自动打开看板：http://127.0.0.1:8765/
4. 右下角托盘图标可：
   - 打开健康看板
   - 开机自动启动
   - 退出

第一次运行如果被 Windows 安全中心拦截，选择「仍要运行」即可。再双击一次不会重复开服务，只会重新打开页面。

## 从源码运行

需要 Python 3.10+（本机开发环境为 Python 3.14）。

```bat
pip install -r requirements.txt
python server.py
```

或双击 `启动监控.bat`。然后访问 http://127.0.0.1:8765/

托盘版：

```bat
python app.py
```

## 重新打包 exe

```bat
build_exe.bat
```

会生成 `电脑健康看板.exe`（约 28 MB，单文件，不依赖本机 Python）。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 看板页面（中文结论 + 实时数据） |
| `server.py` | 本机采集 CPU / 内存 / 磁盘 / 网络，并提供网页 |
| `app.py` | Windows 托盘程序（开机启动、单实例） |
| `电脑健康看板.exe` | 已打包好的独立程序 |
| `build_exe.bat` | 一键重新打包 |
| `启动监控.bat` | 源码方式启动网页服务 |

## 说明

浏览器本身读不到真实的内存、磁盘、网卡信息，所以这不是 Chrome 插件，而是一个很小的本机程序：后台采集，页面展示。
